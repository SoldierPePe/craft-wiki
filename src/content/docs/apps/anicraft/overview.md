AniCraft is an open-source 2D vector animation studio built from scratch in pure Rust. Draw on the stage, key frames on the timeline, and tween them with custom easing curves in a native, familiar animation workflow. It runs on Windows, macOS, Linux, FreeBSD, and in modern web browsers via WebAssembly.

:::caution[Early alpha]
AniCraft is in active early development. It is fully functional for creating vector animations, tweens, symbols, and exports, but features and interfaces may change. Keep backups of your projects and share feedback on [GitHub](https://github.com/storytold/AniCraft/issues) or [Discord](https://discord.gg/artcraft).
:::

## Highlights

- **Familiar interface**: Stage, tools, timeline, layers, keyframes, Properties, and Library sit where animators expect them, with onion skinning for in-betweening.
- **Classic and shape tweens**: Eight easing presets, custom Bézier easing curves, and contour-morphing shape tweens.
- **Symbols and scenes**: Graphic symbols and movie clips with nested timelines, loop modes, mask and guide layers, and multiple scenes.
- **Real vector tools**: Pen, Pencil with curve fitting, geometric shapes, text, Paint Bucket, and Ink Bottle with full point-by-point Bézier editing.
- **Open file formats**: Opens `.fla` and `.xfl` documents, imports SVG artwork, and exports PNG sequences, GIF, SVG frames, sprite sheets, Lottie, and video via FFmpeg.
- **Agent and automation ready**: Full CLI automation, JSON-lines protocol, and Model Context Protocol (MCP) server support.

## Supported formats

- **Documents**: `.anicraft` native project files, Adobe `.fla` and `.xfl` archives.
- **Vector import**: Scalable Vector Graphics (`.svg`).
- **Export**: Animated GIF, PNG frame sequences, SVG frame bundles, sprite sheets, Lottie JSON, and MP4/WebM video through FFmpeg.
